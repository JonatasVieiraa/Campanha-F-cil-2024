# Campanha Fácil 2024

Landing page desenvolvida para auxiliar candidatos com a promoção de produtos eleitorais, oferecendo um calendário de conteúdos estratégico.

## Como Rodar

1. Clone o repositório:

    ```bash
    git clone https://github.com/JonatasVieiraa/Campanha-F-cil-2024.git
    ```

2. Navegue até o diretório:

    ```bash
    cd Campanha-F-cil-2024
    ```

3. Abra `index.html` em seu navegador para visualizar a landing page.

## Estrutura do Projeto

- **index.html**: Modelo da estrutura da página.
- **styles.css**: Folha de estilos para personalização.
- **script.js** : Inclui funcionalidades adicionais ou interações.
